# Kit skills are written from scratch; only public upstreams are credited

Every kit skill is written fresh. It may adapt text from a public upstream (Matt Pocock, Addy Osmani, pstack) under that upstream's license, and take ideas from anywhere. It never takes text from the author's earlier private toolkit, which was written for an employer and is not named anywhere in this repo. `NOTICE.md` credits only public upstreams, and only for what was checked against the upstream's own text. Any credit that has not been checked first goes through a `research` ticket.
